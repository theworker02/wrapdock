# wrapdock

Wrap encode/decode helpers for dock payloads in pipelines.

**Site:** https://theworker02.github.io/wrapdock/

## Install / run

```bash
git clone https://github.com/theworker02/wrapdock.git
cd wrapdock
node src/cli.js
node --test
```
